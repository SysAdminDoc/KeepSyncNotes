# KeepSync Notes v1.56.1

KeepSync Notes now has a self-contained Windows package, a clearer README, and current screenshots from the real app. The new note-relay identity carries through the window icon, package metadata, and GitHub artwork.

- Download `KeepSyncNotes-1.56.1-windows-x64.zip`, extract it, and run `KeepSyncNotes.exe`.
- The package includes the same README shown on GitHub.
- SHA-256 checksums are attached for both Windows downloads.
- The README screenshots use a clearly labeled sample workspace.

The Windows executable is not code-signed because a code-signing certificate was not available on the build machine. Windows may show an unknown publisher warning the first time you run it.
